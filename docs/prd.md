> 项目定位：AI Agent 毕业设计作品（Demo），创业概念验证原型
> 项目名称：JobPrep Agent
> 文档版本：V1.2

## 1 产品概述
### 1.1 产品简介
JobPrep Agent 是一款基于多智能体AI Agent的求职备考演示系统。首期聚焦程序员技术面试，用户粘贴目标岗位JD，系统自动解析岗位技术要求，评估个人与岗位匹配度，生成针对性复习资料，并模拟真实大厂技术面试（支持代码编写、运行、连环追问），面试结束输出结构化评估报告。简历优化模块作为免费辅助功能。

产品底层采用LangGraph实现多Agent编排，具备任务规划、工具调用、RAG知识库、会话状态记忆能力，满足AI Agent毕业设计的技术展示要求；创业层面仅作为概念原型验证，本版本**无任何付费功能**。

### 1.2 产品目标
1. 作品目标：实现一套完整多Agent系统，答辩可演示端到端求职面试闭环，体现Agent任务拆解、工具调用、状态流转、RAG检索、**历史记忆复用**等核心能力。
2. 原型目标：验证「JD驱动 + 历史面试薄弱点追踪」的定向技术面试备考产品思路，收集用户反馈，为后续版本做方案储备（本Demo不做商业化落地）。

### 1.3 范围界定
✅ 包含（MVP）
- JD文本解析、岗位技术要素抽取
- 用户-岗位匹配度打分、能力差距诊断
- 个性化复习清单生成（**支持读取历史面试报告，优先聚焦历史薄弱点**）
- 多轮技术模拟面试，代码在线提交+沙箱执行判题（**二次面试时，基于历史薄弱点出题**）
- 面试全流程记忆、连环追问（基于上一轮回答继续深挖）
- 面试结束结构化评估报告，持久保存历史报告
- 简历优化（对照JD做项目描述优化，免费）

❌ 不包含（延后开发 / 本版本直接剔除）
- 岗位爬虫、岗位推荐、投递管理、面试日程提醒
- 产品/运营/非技术岗位面试能力
- 社区、评论、用户论坛
- 独立App，仅网页H5
- 真人人工辅导
- 支付、订单、套餐、次数扣减、付费弹窗等商业化模块

## 2 用户需求与用户画像
### 2.1 用户画像
**画像A：校招应届生程序员**
- 背景：计算机相关本科/硕士，有课程项目，缺少真实面试经验
- 痛点：盲目刷题，不清楚企业JD真正考察点；面试紧张，不知道如何组织回答，缺少代码面试演练；做完一轮模拟面试后，希望针对性巩固暴露出来的薄弱知识点，而不是重复全套基础面试。
- 行为：集中在秋招/春招，短周期高强度备考，尝试AI工具降低备考成本。

**画像B：社招跳槽程序员（2~8年）**
- 背景：在职开发，时间碎片化，准备跳槽面试
- 痛点：拿到JD，分不清硬性门槛与加分项；很久不手写算法，缺少针对目标公司岗位的专项面试模拟；一轮面试后想集中攻克本次面试暴露的短板。
- 行为：面试前1~7天集中准备，希望获取高质量、定向聚焦薄弱点的模拟面试演练。

### 2.2 用户核心痛点
1. JD信息杂乱，无法快速提炼岗位考察的技术栈、底层原理、项目经验要求
2. 通用刷题平台和目标岗位脱节，复习没有优先级，大量无效学习
3. 普通大模型模拟面试是一问一答，缺少真实面试官的连环追问；代码题无法在线运行判题
4. 面试完成无系统化复盘，不知道回答缺陷、代码优化方向
5. **原有方案缺陷：每次重新生成复习清单和面试题目，不会利用上一轮面试发现的薄弱知识点，重复考察已掌握内容，训练效率低**

### 2.3 用户使用主流程（新增历史薄弱点分支）
1. 用户访问网页，注册/登录（支持游客模式体验基础功能）
2. 粘贴目标岗位JD，粘贴自身简历（可选）
3. Agent自动解析JD，输出岗位画像 + 用户匹配分析报告，标记能力短板
4. 用户选择【生成复习清单】，得到定向知识点、算法题型、项目深挖要点
5. 用户选择【开启模拟面试】，进入多轮技术面试会话
    - 面试官Agent依次出题：理论题 + 算法代码题
    - 用户文字作答 / 在线编写代码提交
    - Agent调用代码沙箱执行代码，自动判断结果
    - 基于用户回答，继续追问边界条件、复杂度、工程优化等问题
6. 面试结束，生成完整面试评估报告，**报告持久存入用户历史记录**
7. 👉【新增分支】用户再次打开该JD对应的复习清单页面：
    - 复习规划Agent读取**该JD下的历史面试评估报告**
    - 梳理区分：用户已掌握知识点、历史暴露薄弱知识点
    - 新生成复习清单**优先聚焦历史薄弱点**，减少重复考察已经掌握的内容
8. 👉【新增分支】再次开启本轮JD的模拟面试：
    - 技术面试官Agent读取历史面试报告，优先针对历史薄弱知识点出题
    - 少量穿插少量已掌握知识点做巩固，避免完全遗忘
9. 用户可选择使用免费简历优化功能，对照该JD优化简历项目描述

## 3 功能详细需求
### 3.1 Agent编排层（后台核心，答辩重点）
Orchestrator总调度Agent：
1. 接收用户输入，识别用户当前阶段（JD解析/复习/面试/报告/简历优化）
2. 任务拆解，分发任务给对应子Agent
3. 维护全局会话状态：记录当前面试进度、已回答题目、历史代码、用户薄弱项
4. 控制子Agent权限，管理工具调用（RAG检索、代码沙箱、**用户历史报告读取**）
5. 管理记忆上下文，保证多轮对话连贯；**支持读取该JD对应的历史面试评估报告作为上下文输入**

> 子Agent列表：JD解析Agent、复习规划Agent、技术面试官Agent、面试评估Agent、简历优化Agent

### 3.2 JD解析Agent
输入：JD文本 + 用户简历文本（可选）
输出：
1. 岗位技术栈清单（必选/加分标签）
2. 岗位硬性门槛、业务背景描述
3. 用户匹配度总分（0~100）
4. 能力差距清单：哪些知识点缺失，哪些项目经验不足
能力说明：
- 抽取技术关键词，调用RAG知识库补充技术含义
- 区分【硬性要求】和【优先加分项】，给复习权重

### 3.3 复习规划Agent（**更新：支持读取历史面试报告**）
输入：JD解析结果、用户能力差距、**可选：同JD下用户历史面试评估报告**
> 判断逻辑：若当前JD存在历史面试评估报告，则启用薄弱点优先模式；无历史报告，使用原始JD短板模式。

输出个性化复习清单：
1. 优先复习知识点（**优先历史面试暴露的薄弱点，按岗位权重排序**）
2. 推荐算法题型（聚焦薄弱知识点对应的算法类型）
3. 项目深挖方向：针对面试中暴露不足的项目经验点
4. 参考资料指引（来自RAG面试知识库）
5. 新增板块：📝 历史掌握情况总结
    - ✅ 已掌握知识点（上一轮面试表现良好，减少复习权重）
    - ⚠️ 历史薄弱知识点（本次复习重点）

### 3.4 技术面试官Agent（**更新：支持读取历史面试报告，薄弱点定向出题**）
角色：中大厂资深开发面试官，风格严谨，会连环追问
输入：JD解析结果、用户简历、**可选：同JD下历史面试评估报告**
> 判断逻辑：存在历史面试报告 → 进入针对性复习面试模式；无历史报告，使用完整岗位面试模式

能力：
1. 根据JD和用户简历，**优先选取历史薄弱知识点动态生成面试题目**；少量穿插已掌握知识点用于巩固
2. 多轮递进追问，记住上一轮回答，持续深挖
3. 遇到代码题，展示题目，提供代码编辑框
4. 用户提交代码后，触发工具调用：代码沙箱执行，运行测试用例
5. 基于代码运行结果，追问时间复杂度、边界case、工程优化
约束：
- 不会一次性抛出全部题目；模拟真实面试节奏
- 题目不能脱离当前JD技术栈，避免无关考题
- 针对薄弱点出题，但不完全剔除已掌握知识点，防止遗忘

### 3.5 代码沙箱工具（工具层）
能力：
1. 支持Python/JavaScript等主流开发语言（首期优先JS、Python）
2. 隔离环境执行代码，限制最大运行时间、内存，禁止系统高危调用
3. 内置测试用例，比对输出，返回运行结果、报错信息
4. 输出代码得分（正确性、鲁棒性、代码规范）
> 安全限制：Demo严格限制执行权限，防止恶意代码攻击

### 3.6 面试评估Agent
触发时机：用户结束面试会话
输入：面试全流程对话记录、代码提交记录、沙箱运行结果
输出结构化面试报告：
1. 总体面试得分
2. 分项打分：理论基础、代码编写、问题分析、表达能力
3. 每道题点评：回答优点、缺失要点、改进建议
4. 薄弱知识点汇总 + 后续复习建议
> 报告持久化保存到用户中心，绑定对应岗位JD，用于下一轮复习与面试。

### 3.7 简历优化Agent（免费辅助模块）
输入：用户简历文本 + 当前JD
输出：
1. 项目描述润色，对齐JD技术关键词
2. 优化建议：项目难点、成果量化、表述问题
> 定位：轻量化，不做深度简历排版，仅文本内容优化

### 3.8 前端网页功能（页面更新）
1. 首页：功能介绍，JD分析入口，模拟面试入口
2. JD上传页：文本框粘贴JD、粘贴简历
3. 报告展示页：匹配报告、复习清单，支持复制文本
4. **复习清单页面【新增板块：历史掌握情况总结】**
    - ✅ 已掌握知识点
    - ⚠️ 历史薄弱知识点
    - 提示文字：本次复习已参考你在此岗位的上一轮模拟面试结果，优先聚焦薄弱点
5. 模拟面试会话页：对话窗口 + 在线代码编辑器
6. 面试报告页面，查看完整评估结果
7. 用户中心：历史会话记录、历史面试报告（报告绑定对应JD）

## 4 非功能需求
1. **AI稳定性**：减少幻觉；面试题目、知识点优先从RAG知识库检索，大模型生成作为补充
2. **会话记忆 & 长期记忆**：
    - 单会话内保存面试全流程上下文；
    - 用户历史面试报告持久存储，**按JD维度关联保存，支持后续复习/面试读取**
3. **安全**：代码沙箱隔离执行，限制资源；用户简历、JD文本加密存储
4. **演示友好**：答辩时可一键从头跑通完整闭环，流程直观；可以演示「第一轮完整面试 → 第二轮基于薄弱点定向面试」的效果
5. **可扩展性**：Agent架构预留扩展接口，后续支持产品、运营等非技术岗位

## 6 技术架构简述（PRD内精简版，答辩使用）
```
前端网页 (H5)
↓
Orchestrator 编排 Agent（总调度、状态管理、任务分发、读取用户历史报告）
↓
多专业子 Agent 组：JD 解析 Agent / 复习规划 Agent / 面试官 Agent / 评估 Agent / 简历 Agent

工具层：文本解析工具｜RAG 检索工具｜代码沙箱工具｜打分工具｜历史记录读取工具

大模型基座
```

## 8 风险与应对方案
|风险|应对方案|
| ---- | ---- |
|代码沙箱安全风险|限制CPU、内存、执行时长；禁用文件读写、系统调用；Demo不开放网络访问|
|AI面试题幻觉、答案错误|面试知识点依赖RAG知识库检索权威面经，大模型结果做校验|
|对话生硬，不像真实面试官|面试官Agent角色Prompt精细化，增加追问策略；面试流程状态机约束对话节奏|
|历史薄弱点识别不准|评估Agent输出结构化、标准化的知识点标签，方便后续Agent读取解析，减少自由文本解析误差|
|用户不信任AI评估结果|报告写明打分依据，引用知识库资料；标注AI仅供学习参考，不能等同于真实面试官|

## 10 附录
### 10.1 术语说明
- Agent：智能体，具备感知、规划、调用工具能力
- Orchestrator：编排调度智能体，负责任务拆解与多Agent调度
- RAG：检索增强生成，从面试知识库检索资料，减少大模型幻觉
- 会话状态：记录当前用户在流程中的阶段，LangGraph State管理
- 代码沙箱：隔离环境，安全执行用户提交代码
- **长期记忆（持久化历史报告）**：用户完成面试后的评估报告持久存储，绑定对应岗位JD，作为后续复习、面试的输入上下文

### 10.2 答辩演示脚本（精简，**新增第二轮薄弱点面试演示**）
1. 第一轮演示：粘贴一份后端岗位JD，系统解析岗位技术栈，输出匹配报告和短板
2. 生成第一轮复习清单，启动模拟面试，Agent提问理论+算法代码题；提交代码，沙箱运行，Agent追问优化思路
3. 结束面试，生成第一轮面试评估报告并保存至用户中心
4. 👉第二轮演示：回到复习清单页面；系统读取上一轮历史面试报告，生成**聚焦历史薄弱点**的新版复习清单，展示「已掌握 / 薄弱知识点」板块
5. 再次开启模拟面试：面试官优先针对历史薄弱知识点出题，少量已掌握知识点巩固
6. 演示免费简历优化，基于JD优化简历项目描述
